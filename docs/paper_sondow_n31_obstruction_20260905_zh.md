# n=31 的真实整数核：严格的有限层长度障碍

日期：2026-09-05。本文给出一个有限层定理，不声称排除其他层或整个 Sondow 路线。

## 1. 定理与证书数据

取原 Sondow 指数矩阵 E，其列为 k=31,…,62，行为 p≤124 的全部质数。
令

```text
N=16^62=2^248，w_k=D_k*16^(62-k)，
C(x)=max(sum max(x_k,0)*w_k, sum max(-x_k,0)*w_k)。
```

**有限层定理。** 对每个非零整数向量 x，若 E x=0，则 C(x)>N。
因此这一层的任意双向量即便投影行列式非零，强化证书
`q≥floor(N/max(C(a),C(b)))+1` 也只能给出平凡的 q≥1。

两条完整整数向量见
[证书数据](../paper/computations/sondow_n31_kernel_obstruction_20260905.json)。
以下记它们为 a、b。它们由整数核与格基约化计算发现；证明只依赖下面列出的
独立整数检查，不依赖搜索器正确性、约化最优性或浮点误差估计。

## 2. 两个向量确实生成全部整数核

从原三重幂积重新计算 E，而不是读取搜索程序输出的 E。
原定义给 E 为 30×32 整数矩阵。其前 30 列行列式模 1009 为 511；
1009 的素性通过不超过 31 的试除核验。
故 rank(E)=30，其有理核的维数恰为 2。

证书还满足以下精确整数等式：

```text
E a=E b=0；
gcd_(i<j) |a_i*b_j-a_j*b_i|=1。
```

第二式保证 a、b 线性独立。任给整数核向量 x，有唯一有理数 alpha、beta，
使 x=alpha*a+beta*b。设 d_ij=a_i*b_j-a_j*b_i，则

```text
alpha*d_ij=x_i*b_j-x_j*b_i in Z，
beta*d_ij=a_i*x_j-a_j*x_i in Z。
```

这些 d_ij 的最大公约数为 1，Bezout 的整数线性组合给 alpha、beta 都为整数。
因此任何整数核向量都可以写成 z1*a+z2*b，z1、z2 为整数。
这里检验的是未加权向量的子式；不能把含权重 w_k 的子式代入这个判据。

额外核验还给出 (Q·a)(T·b)-(Q·b)(T·a)≠0，说明这确实是一层具有二维有效投影
的真实矩阵。长度障碍不能解释成根本没有有效方向。

## 3. 正交投影给出全体向量下界

记 A=(w_k*a_k)、B=(w_k*b_k)，点积均为普通欧氏点积。定义有理数

```text
g1=A·A，g2=B·B-(A·B)^2/g1。
```

精确整数核验得到

```text
floor(log2(g1))=4952，floor(log2(g2))=4955。
```

代码不计算浮点对数。第一项由整数 bit_length 得出；第二项先作整数除法
`floor(((A·A)(B·B)-(A·B)^2)/(A·A))`，再计算其 bit_length。
对正有理数 ≥1，先取整数部分不改变它所在的二次幂区间。
特别地，两者都严格大于 `2N^2=2^497`；也可以直接交叉相乘检查，不用对数描述。

对任意非零 x=z1*a+z2*b：

- 若 z2=0，则 z1 为非零整数，norm2(Wx)^2=z1^2*g1≥g1。
- 若 z2≠0，投影到 B*=B-(A·B/g1)A 的方向，得到 z2*B*，
  因而 norm2(Wx)^2≥z2^2*g2≥g2。

所以每个非零整数核向量都满足 norm2(Wx)^2>2N^2。
另一方面，令 P、M 分别是 Wx 的正、负部分的绝对值和，则

```text
norm2(Wx)^2≤P^2+M^2≤2*max(P,M)^2=2*C(x)^2。
```

于是 C(x)>N，完成定理的证明。
这个论证不要求 a、b 是最短向量，也不需要信任任何 LLL 条件。

## 4. 独立复算

运行：

```text
python paper/computations/check_sondow_n31_obstruction.py
```

[核验脚本](../paper/computations/check_sondow_n31_obstruction.py) 仅使用 Python 标准库。
它从原三重指数和式重新构造 E、D、Q、T，逐项检查两个核等式，
重算非零模子式、所有二阶子式的 gcd，以及两个严格的 Gram 不等式。
最终检查是完整整数等式、整除、比较，不以数值误差或抽样代替。

## 5. 对核心候选路线的实际含义

这一结果排除了 n=31 上全部非零整数核向量达到 C≤N，因而比有限次搜索失败更强。
它不证明其他层也失败，更不证明 Sondow 无理性路线不可能。
对于较大 n，公共核可有很多短向量；届时需研究除去公共核后的有效方向长度，
不能把本层的二维全核论证原样套到高维核。
无界多个 n 上 C/16^(2n)→0 的有效双向量族仍未证明。
