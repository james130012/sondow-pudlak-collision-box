# 真实积分二次型的四层精确障碍证书

日期：2026-09-05。以下是有限数学定理及独立整数核验，不是渐近结论或 Lean 验证。

对 n=34、48、64、96，真实 Sondow 整数核的每个有效方向 a 都满足

`U_n(a)²>1`，`C_beta(a)>1`。

所以这四层的有理积分符号证书、保留交叉项的二次型证书，以及逐向量取两者较小值
的组合证书，都不能给出非平凡分母界。这是对所有有效整数方向的结论，
不局限于候选搜索返回的基向量。其他层及其他积分估计方法不在此结论范围内。

## 1. 使用的二次型与有限格

沿用 [二次型纸面证明](paper_sondow_moment_quadratic_certificate_20260905_zh.md) 的记号：

`beta_m=1/(4m² binom(2m,m)²)`，
`U_n(a)²=beta_n sum_(i,j=0,…,n) a_(n+i)D_(n+i)a_(n+j)D_(n+j) beta_(n+i+j)`。

原积分证明此矩阵在实空间正定，并给非零 a 的严格余项上界。
记 Lambda=ker_Z E、K=ker_Z(E,Q,T)，有效方向指 a∈Lambda 且 a∉K。
在该二次型给出的内积下，沿 span_R(K) 作正交投影，商格的第一连续极小值平方
记为 alpha。则所有有效 a 都有 U_n(a)²≥alpha。

同一纸面证明还给

`U_n(a)²<(16/9) C_beta(a)²`，a≠0。

因此 alpha>16/9 同时推出本稿开头的两条严格结论。这里不用从旧对角权重比较
新范数，而是直接认证包含全部交叉项的有理矩阵。

## 2. 全部缩放因子及投影方程

令 l 为整数 4m² binom(2m,m)²（m=n,…,3n）的最小公倍数，定义整数矩阵

`H_ij=D_(n+i)D_(n+j) * l/[4(n+i+j)² binom(2(n+i+j),n+i+j)²]`。

令 d0=l*4n² binom(2n,n)²，则 H/d0 恰为上节二次型矩阵。
所有除法整除；n+i+j≥n≥1，没有 beta_0。

从 [原四层证书](paper_sondow_finite_quotient_certificates_20260905_zh.md) 取得同一完整
整数核的行基 B 和同一整数可逆换基 V。原认证给 V B 的前两行生成完整有效商，
余行生成全部 K；不是只挑出两条偶然独立向量。
计算整数 Gram `G=V B H B^T V^T`，将其分块为

```text
G = [[S, Z^T],
     [Z, R]]。
```

R 对应 K 的基。H 正定、K 的这些行线性无关，故 R 可逆。
新证书给正整数 d1 和整数矩阵 X，检查器验证

`R X=d1 Z`。

所以整数矩阵 Q=d1 S-Z^T X 满足

`Q/(d0*d1)=(S-Z^T R^(-1) Z)/d0`，

右端就是新内积下真实商格的 Gram 矩阵。不能少除 d0，也不能把 d1 当作新
内积的权重；两个分母在最后相乘。

再给 2×2 整数矩阵 J，检查 det J=±1，并计算 `J Q J^T`。设其条目为
[[a,b],[b,c]]，核查

`0<a≤c`，`2|b|≤a`，`det(Q)>0`。

Gauss 约化证明给真实第一、第二连续极小值平方分别为

`alpha=a/(d0*d1)`，`delta=c/(d0*d1)`。

最后以整数交叉乘法检查

`a>d0*d1`，`9a>16d0*d1`。

这两项恰是严格 alpha>1、alpha>16/9。第一项的等号不能作为排除依据，
因为证书成本恰为 1 时，原严格余项界仍可排除分母 1。

## 3. 已通过的精确有限结果

表中 e=floor(log2 x) 只表示准确有理数满足 2^e≤x<2^(e+1)，不用浮点对数。

| n | 完整整数核维数 | floor(log2 alpha) | floor(log2 delta) | alpha>16/9 |
| --- | ---: | ---: | ---: | --- |
| 34 | 3 | 20 | 215 | 是 |
| 48 | 6 | 16 | 274 | 是 |
| 64 | 11 | 4 | 355 | 是 |
| 96 | 21 | 2 | 473 | 是 |

检查器已经对四层全部运行通过。尤其最后两层的判定补充了
[加强积分界稿](paper_sondow_beta_integral_bound_20260905_zh.md) 中旧权重比较未能
判定的情况：旧比较未通过仍然只是未判定，但现在另有精确二次型证书提供障碍。
不是从“未通过旧判据”反推新结论。

本稿不从这些逐层事实推断 alpha 随 n 的趋势，也不推断所有充分大层都有障碍。
大的第二连续极小值同样只是这些具体层上的定理。

每份数据引用同层的已有基证书，并提供 d0、l、d1、X、J；没有重复存放巨大核基。
[独立检查器](../paper/computations/check_sondow_moment_obstructions.py) 只用 Python 标准库：

1. 调用原检查器，按 Sondow 原三重指数和重建 E/Q/T，认证非零秩子式、核基最大阶
   子式 gcd=1、完整整数核、整数可逆像换基及完整公共核。
2. 取得同一次认证使用的原数据对象，重新用整数 binomial/lcm 构造 H、d0。
3. 逐项验证投影方程、2×2 整数换基、正定与 Gauss 不等式以及最后两个严格阈值。

候选生成器的矩阵求逆、LLL 或浮点质量均不作为检查器前提。
使用的是纸面已证明的正定积分矩阵；不以计算得到一个正对角条目代替整体正定性。
二次型缩放、商基完整性、投影方向和两个阈值另外经过独立代码及数学审查。

从项目根目录运行：

```text
python -B paper/computations/check_sondow_moment_obstructions.py 34 48 64 96
```

这个命令会先输出每层原证书的核验结果，再输出新二次型结果。
检查通过只证明这里四个有限层定理，不能据此标记最终数论桥或无理性结论完成。
