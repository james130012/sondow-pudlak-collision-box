# 整数对数分离候选：一次来源代参与量级核查

日期：2026-09-05。本文只检验一条数论补桥候选，不恢复形式化工作。

结论：Hermite–Lindemann 的非零性本身不能产生所需矛盾；下面实际核对并代入的
Mahler 有效分离定理，只给出关于外层 n 的双指数小下界，弱于工作稿已有的积分下界。
因此这条通用定理不能补齐 Sondow 源端到无理性结论的缺口。
这不是对所有特殊结构方法的不可能性证明，也不声称列出的历史常数是现今最优常数。

## 1. 变量和必须比较的两个量

沿用 [统一纸面稿](../paper/full_paper_proof_working_zh.md) 第 2–3 节。
假设 gamma=p/q，其中 p 为整数、q 为固定正整数，定义

```text
Z_n = q T_n − D_n B_n p，
delta_n = q log S_n − Z_n = q D_n I_n。
```

注意这里 delta_n 是 q 倍残差；统一稿的 Y_n 是 delta_n/q。
对每个 n≥1，已有

```text
q*(9/256)^n/64 ≤ delta_n < q*2^(−n)。              (1)
```

为了直接否定有理性假设，需要另外得到与右边不相容的下界。
仅得出 delta_n 不为零没有用，因为式 (1) 已经严格给出正性。

还有一项应当利用的整除事实：当 q≤2n 时，q 整除 D_n，因此

```text
m_n = Z_n/q = T_n − (D_n/q)*B_n*p
```

本身是整数，且 0<log S_n−m_n=D_n I_n<2^(−n)。
下面先按题设的 Z_n 代入，再检查用 m_n 消去固定 q 后能否改变结论。

## 2. 完整整数的高度不是压缩指数的位数

统一稿已证明

```text
(log 2)*4^n/[2(n+1)^2] ≤ log S_n
                      ≤ 2(n+1)^3*36^n*log(2n)。   (2)
```

右侧来自聚合指数和不超过 2(n+1)^3*36^n、各底数不超过 2n。
由 Z_n=q log S_n−delta_n，式 (1)、(2) 得

```text
q*(log 2)*4^n/[2(n+1)^2] − q*2^(−n) < Z_n
Z_n ≤ 2q(n+1)^3*36^n*log(2n)。                   (3)
```

因此对固定 q，在本有理性假设下，Z_n 最终为正整数且趋于无穷。
准确区分下列量级：

- Z_n 的数值是 exp(Theta(n))，二进制位数是 Theta(n)；
- log S_n 是 exp(Theta(n))；完整 S_n 的二进制位数也是 exp(Theta(n))；
- S_n 的通常整数高度 H(S_n)=S_n 是 exp(exp(Theta(n)))；
- 用小底数及指数列表压缩 S_n，并不改变代数数 S_n 的高度。

这里 Theta 的上下正常数可以不同；式 (2)、(3) 是不依赖这些记号的具体界。
把压缩列表大小代入一个要求 log H(S_n) 的定理，会少掉一个指数层级。

## 3. 可直接使用的一次来源定理

核对了 Kurt Mahler, *On the approximation of logarithms of algebraic numbers*,
Philosophical Transactions of the Royal Society of London, Series A 245 (1953),
371–398，原文第 397、398 页。

原文 Theorem 7 断言：对充分大的正整数 f 和任意整数 a，

```text
|log f − a| > f^(−40 log log f)。                (4)
```

原文 Theorem 8 断言：对充分大的正整数 a 和任意整数 f，

```text
|exp(a) − f| > a^(−40a)。                       (5)
```

来源：[Mahler 原始论文 PDF，第 397–398 页](https://carmamaths.org/resources/mahler/docs/118.pdf)。
本核查读取了原文并检查了这两页的图像，避免把扫描文本中的负指数识别错误带入计算。
这里使用原文的“充分大”版本，不把它伪装成已列出具体初始阈值的版本。

### 3.1 对 Theorem 7 的直接代入

取 f=S_n^q、a=Z_n。两者都是整数，且 f 趋于无穷，满足定理适用条件。
由 log f=q log S_n，得

```text
delta_n > exp(−40 q log S_n * log(q log S_n))。   (6)
```

令 H_n=2q(n+1)^3*36^n*log(2n)。在 H_n>1 的共同尾部，式 (2) 给出

```text
delta_n > exp(−40 H_n log H_n)。                 (7)
```

式 (6) 比使用 H_n 的式 (7) 强，但仍不足：由式 (2) 的下界，
40 q log S_n * log(q log S_n) 的增长快于任何固定倍数的 n。
所以式 (6) 的右边最终远小于 q*(9/256)^n/64，后者早已由式 (1) 证明。
这不是仅因我们使用了粗糙上界 H_n；定理在真实 S_n 上的下界本身就有该量级障碍。

### 3.2 对 Theorem 8 的交叉核查

取 a=Z_n、f=S_n^q。到共同尾部有 0<delta_n<1，因此

```text
S_n^q − exp(Z_n)
  = exp(Z_n+delta_n)*(1−exp(−delta_n))
  < exp(Z_n+1)*delta_n。
```

与式 (5) 联立，得到

```text
delta_n > exp(−40 Z_n log Z_n − Z_n − 1)。        (8)
```

由式 (3)，这仍是关于 n 的双指数小下界，不能与 q*2^(−n) 冲突。
两个定理分别在整数对数侧与整数指数侧代入，结论量级一致。

### 3.3 利用 q 整除 D_n 的加强仍不够

在 q≤2n 的尾部，直接在 Theorem 7 中取 f=S_n、a=m_n，得到更强的

```text
delta_n > q*exp(−40 log S_n * log log S_n)。      (10)
```

这消去了式 (6) 指数内的固定 q 因子，却没有改变双指数小的量级。
用 Theorem 8 的 a=m_n、f=S_n 也给出同样障碍。
所以失败原因不是遗漏分母清除，而是完整整数的对数高度已经指数增长。

## 4. 为什么不能把整数项当作另一个代数数的对数

压缩幂积写法给出

```text
delta_n = sum(k=1,…,n) q*e_(n,k)*log(n+k) − Z_n。
```

纯对数线性形式定理所要求的是代数数的对数之线性组合。
将最后一项写成 −Z_n*log(e) 时，底数 e 不是代数数，不能套用要求所有底数
为代数数的 Baker/Matveev 型纯对数线性形式估计。
某个更一般的有效 Lindemann 定理若明确允许独立代数常数项，当然可以另行检验；
必须展示它真实的次数、高度、维数和系数参数，不能把纯对数版本无条件延伸。

同样，固定整数 S 的 log S 是超越数，不排斥它与一个有理数之间存在很小的正差。
本项目的 S=S_n 还随 n 改变，不能把依赖固定 S 的逼近常数当作统一常数。

## 5. 仅凭整数性和上述粗高度不可能获得所需统一分离

下面是独立的简单引理，不使用任何关于 gamma 的结论。

**引理。** 固定 q≥1。对每个正整数 m，令

```text
S(m) = floor(exp(m/q))+1。
```

则 S(m) 是整数，而且

```text
0 < q log S(m) − m < q*exp(−m/q)。               (9)
```

证明：设 x=exp(m/q)。无论 x 是否整数，总有 x<S(m)≤x+1。
所以 0<log(S(m)/x)≤log(1+1/x)<1/x；乘以 q 即得。证毕。

例如取 m=4^n，则 log S(m)=4^n/q+o(1)，完整整数的高度仍是
exp(exp(Theta(n)))，且正残差小于 q*exp(−4^n/q)，远小于 q*2^(−n)。
因此，对任意这种高度的整数，只凭“整数、正残差、固定 q”的统一下界，
不可能保证残差达到本路线所需的指数尺度。

本引理中的 S(m) 不等于 Sondow 的特殊幂积；它也不满足式 (1) 的积分下界。
该例准确排除的是忽略特殊结构的通用推理，不能据此否定利用特殊幂积的新论证。

### 5.1 同时保留现用积分数值上下界的强化例子

还可以构造一个与全部现用积分数值界相容的替代数据族。沿用真实的
D_n=lcm(1,…,2n)，令

```text
M_n=4^n，epsilon_n=(D_n/2)*16^(−n)，
S*_n=floor(exp(M_n+epsilon_n))+1，
r_n=log S*_n−M_n，I*_n=r_n/D_n。
```

对 n≥1，4^n≥4n>n log16，其中首个不等式可直接归纳证明。
由 D_n≥2，有 epsilon_n≥16^(−n)，从而

```text
exp(−M_n−epsilon_n)<16^(−n)≤epsilon_n。
```

令 x=exp(M_n+epsilon_n)。由 x<floor(x)+1≤x+1 及 log(1+t)<t，

```text
epsilon_n<r_n<epsilon_n+exp(−M_n−epsilon_n)<2 epsilon_n。
```

除以正整数 D_n，便得

```text
(1/2)*16^(−n)<I*_n<16^(−n)。
```

而 a_n=(9/256)^n/64 满足

```text
a_n / [(1/2)*16^(−n)] = (9/16)^n/32 < 1。
```

因此同时有

```text
0<a_n<I*_n<16^(−n)，
a_n<D_n I*_n<D_n16^(−n)<2^(−n)，
log S*_n−M_n=D_n I*_n，M_n 为整数。              (11)
```

最后一个上界使用真实 D_n<8^n。又有 r_n<2^(−n)，故

```text
log S*_n=4^n+O(2^(−n))，
H(S*_n)=exp(exp(Theta(n)))。
```

可见整数残差、同一个 D_n、现用积分数值上下界和粗高度彼此相容。
该例只能证明这些弱化信息不够产生矛盾；S*_n 不是原 Sondow 幂积，
I*_n 也不是原二重积分，原 T_n 的具体调和数恒等式同样没有在此保留。
它不否定使用这些精确结构建立新的数论结论。

这里 epsilon_n 中的 D_n/2 因子是保留 I*_n≥a_n 所需的修正。
若直接取 epsilon_n=16^(−n)，仍能证明 a_n<D_n I*_n<2^(−n)，
却没有由该计算证明 I*_n≥a_n；不能把那一较弱版本称为保留全部积分数值界。

## 6. 对主路线的实际影响

这一候选没有闭合主桥。它已经得到可核查的结论：通用非零性无助于正残差，
上述有效分离定理在真实高度上给出的下界弱于现有积分估计。
若继续此方向，必须证明专门针对 Sondow 幂积的分离或分数部分行为，
并展示其下界如何最终超过 q*2^(−n)，或推出统一稿第 3.8 节的无界整层拒绝。
目前没有这样的新定理；不能把“有效超越估计”四个字作为已完成桥接的替代物。
