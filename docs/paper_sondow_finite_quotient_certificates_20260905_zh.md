# 四个真实层的有效商格障碍：独立整数证书

日期：2026-09-05。本稿记录有限层定理；没有推断任何渐近排除结论。

## 1. 准确结论

对 n=34、48、64、96 的每一个值，使用原 Sondow 矩阵
E_(p,k)=v_p(S_k)，k=n,…,2n，p≤4n 为质数。
令 Lambda=ker_Z E、K=ker_Z(E,Q,T)，并令

```text
N=16^(2n)，w_k=D_k*16^(2n-k)，
C(x)=max(sum max(x_k,0)*w_k, sum max(-x_k,0)*w_k)。
```

**有限层定理。** 在上述每个 n 上，所有 x in Lambda 且 (Q·x,T·x)≠(0,0)
都满足 C(x)>N。因此任何投影行列式非零的双向量的联合成本也超过 N，
当前强化分母公式只能给出 q≥1。

这一结论不排除公共核中的短向量；它专门约束有效方向。
n=31 的更早证书约束整个非零整数核，见
[n=31 证明](paper_sondow_n31_obstruction_20260905_zh.md)。

## 2. 每个有限整数证书证明什么

独立检查器从原三重指数和式重建 E、D、Q、T。随后依次检查：

1. 核基 B 的每一行满足原 E；一个模素数 1009 的非零子式证明
   rank E≥m-d；一组 B 的 d 阶子式的 gcd 为 1。
   后者同时证明 B 秩为 d 且其整数行格饱和，所以 B 生成整个整数核。
2. 一个整数矩阵 U 满足 det U=±1；U 对各基向量的 (Q,T) 像只在前两行非零，
   这两行行列式非零。于是 UB 的其余行恰构成完整公共核基，前两行给完整整数商基。
3. 用原权重加权，记前两行为 A、其余行为 C0。
   直接计算 R=C0*C0^T、Z=C0*A^T、S=A*A^T。
   给定正整数 D 和整数矩阵 X，核验 R X=D Z；商格 Gram 的分子就是
   D S-Z^T X，分母为 D。检查过程不求浮点逆矩阵。
4. 给定 2×2 整数可逆换基 J，核验约化 Gram 的对角元 alpha≤delta，
   且 2|beta|≤alpha。二维整数二次型的初等证明给出最短平方恰为 alpha。
5. 清分母后检查严格不等式 alpha>2N²。

证明依据是 [有效商格障碍定理](paper_sondow_quotient_obstruction_20260905_zh.md)。
最后一步对每个有效整数向量给出

```text
2*C(x)^2≥norm2(Wx)^2≥其非零商投影的平方长度≥alpha>2N²，
```

因此 C(x)>N。这里没有假定任何候选向量已经最短，也没有信任 LLL 输出的质量。

每一行还逐项通过原核等式、饱和 gcd=1、整数换基可逆性、投影线性方程、

与之相比，[像指数判据](paper_sondow_quotient_volume_20260905_zh.md) 在这四层都未通过。

这说明两个判据确实有不同强度；便宜判据未通过不能当成好证书存在的证据。

## 5. 结论的边界

这些有限层不能提供当前类型的非平凡分母证书，已经是可独立复核的结论。
它们不证明其余 n 同样失败，也不证明 Sondow 的其他用法不可能。
表中两组指数的差不能当作渐近规律：整数核和像格随 n 改变，当前没有控制该变化的定理。

核心仍未补齐的是无界多个 n 上有效双向量及 C/16^(2n)→0 的构造，
或另一条独立的实际数论归约。本稿没有将若干有限障碍替代这项无穷参数义务。
