# 保留积分交叉项的有理正定二次型证书

日期：2026-09-05。本文直接使用真实 Sondow 积分，证明一个严格的有理二次型上界，
并精确比较它与既有 C_beta 符号成本。本次不运行大规模整数核或商格计算，
不以新二次型的正定性代替有效投影条件，也没有证明渐近有效双向量存在。

## 1. 原积分与两个有限测度

对整数 m≥1，设

```text
B_m=binom(2m,m)，beta_m=1/(4m² B_m²)，
t=x(1−x)y(1−y)，d(x,y)=−(1−xy)log(xy)，
I_m=∫∫ t^m/d(x,y) dx dy，积分域为 (0,1)²。
```

原积分及严格分母估计已在
[有理积分加强界](paper_sondow_beta_integral_bound_20260905_zh.md) 中核清：

```text
d(x,y)>4(1−x)(1−y)>0，
∫∫ t^m/[4(1−x)(1−y)] dx dy=beta_m，
0<I_m<beta_m。                                      (1)
```

固定 n≥1，定义有限正测度

```text
d lambda_n = t^n/d(x,y) dx dy，
d nu_n = t^n/[4(1−x)(1−y)] dx dy。
```

二者总质量分别为 I_n、beta_n，并且前者的密度在开正方形内处处严格小于后者。
nu_n 的密度是

```text
(1/4) x^n(1−x)^(n−1)y^n(1−y)^(n−1)。                (2)
```

所以四条边和四个角点均不产生不可积性，n=1 也适用。可以先在内部紧矩形积分，
再由非负单调极限得到式 (1)。一般带符号被积函数则使用式 (2) 的有限支配。
本文没有把无权的 1/d 或 1/[(1−x)(1−y)] 误当成有限测度。

## 2. 严格二次型上界，包括零余项

令 k=n+i，i=0,…,n。对任意实向量 a=(a_n,…,a_(2n))，设

```text
c_i=a_(n+i) D_(n+i)，F_a(t)=sum(i=0,…,n) c_i t^i，
r(a)=sum(k=n,…,2n) a_k D_k I_k = ∫∫ F_a(t) d lambda_n。
```

F_a 是闭区间 [0,1/16] 上有界的多项式。因此 F_a 与 F_a² 对上述两个有限测度
都可积，有限项求和与积分的交换合法。

定义具有有理系数的平方上界（a 为有理或整数向量时，其值为有理数）

```text
U_n(a)² = beta_n * sum(i,j=0,…,n) c_i c_j beta_(n+i+j)。 (3)
```

**定理 1。** 若 a≠0，则

```text
0<U_n(a)²，且 |r(a)|²<U_n(a)²。                      (4)
```

式中的两条不等式在 r(a)=0 时仍成立。a=0 时两边都为 0，不能声称严格不等式。

证明：先令 J=∫∫ F_a(t)² d lambda_n。Cauchy–Schwarz 给出

```text
|r(a)|²≤I_n J。                                     (5)
```

由于各 D_k>0，a≠0 保证 F_a 非零。t 的取值包含整个 (0,1/16)；非零多项式
不能在这个区间处处为零。取一个 F_a(t)≠0 的内部点，再取其周围足够小的开矩形，
F_a(t)² 在其中严格为正。于是 J>0，且式 (1) 的严格密度比较给出

```text
J < ∫∫ F_a(t)² d nu_n
  = sum(i,j=0,…,n) c_i c_j beta_(n+i+j)。            (6)
```

这里必须先对整个非负平方 F_a² 作密度比较，再展开有限和。
当 c_i c_j<0 时，不能对单个交叉项套用相同方向的积分不等式。

式 (5)、I_n<beta_n 与式 (6) 给出式 (4)。严格性来自非零多项式和严格密度比较，
不依赖 Cauchy–Schwarz 自身是否取等，也不依赖 r(a)≠0。证毕。

## 3. 矩阵确实正定

令 M_n 为 (n+1)×(n+1) 的有理对称矩阵，索引从 0 开始：

```text
(M_n)_(i,j)=beta_n D_(n+i)D_(n+j) beta_(n+i+j)。     (7)
```

则 U_n(a)²=a^T M_n a。对任意非零实 a，

```text
a^T M_n a=beta_n ∫∫ F_a(t)² d nu_n>0。
```

因此 M_n 在整个实系数空间正定，限制到真实 E 核的任意实子空间后仍正定。
这不是仅根据条目为正得出的结论：正定性使用了非零多项式不可能在整个积分区间消失。

所有 beta 的索引均在 n,…,3n，始终≥1；不存在 beta_0 的未定义端点。
二次型、基变换 Gram 矩阵和有限证书都可用整数与有理数精确计算。
存在很大的正负交叉项抵消时，浮点计算的负值或近零值不能充当正定性或证书结论。

## 4. 真实整数核中的双向量证书及严格端点

沿用真实质数指数矩阵 E、Q_k=D_k B_k、T_k=D_k A_k。
对整数 a in ker_Z E，原恒等式精确给出

```text
r(a)=gamma*(Q a)−T a。                              (8)
```

设 a、b 都在该整数核中，且

```text
Delta=(Q a)(T b)−(Q b)(T a)≠0，
M=max(U_n(a)²,U_n(b)²)>0。                          (9)
```

**定理 2。** 若 gamma=p/q，p 为整数、q 为正整数，则

```text
q² M>1，
q≥floor(sqrt(1/M))+1。                              (10)
```

证明：q r(a)=p Q a−q T a，q r(b)=p Q b−q T b 都是整数。
它们不能同时为零；否则两条像向量都与 (q,p) 共线，与 Delta≠0 矛盾。
取其中非零者 x，则

```text
1≤q² r(x)²<q² U_n(x)²≤q² M。
```

这就证明式 (10)。即使另一条向量的余项恰为零，也不影响证明。
若去掉 Delta≠0，非零 E 核向量仍可能落在 ker(E,Q,T)，不能推出式 (10)。

有限核验无需计算无理平方根：对待排除的整数分母上界 q_0，精确核查
q_0² M≤1，就排除所有 1≤q≤q_0。若 M=s/t，s,t 为正整数，式 (10) 的整数门槛也可用
floor(sqrt(floor(t/s))) 计算。

特别地：

- M=1 仍排除 q=1，得到 q≥2；证书通过条件包含等号 M≤1。
- 若另有经过独立认证的有效商格计算，证明每个有效方向的 U_n(a)²≥alpha，
  则 alpha>1 足以排除本层非平凡证书。仅有 alpha≥1 不足以排除等号处的证书。
- 正定矩阵、一个短核向量或一对实投影向量，都不能替代整数 a、b 及 Delta≠0。

## 5. 与 C_beta 的普遍比较

对同一向量 a，令

```text
z_i=c_i beta_(n+i)，
P=sum max(z_i,0)，N=sum max(−z_i,0)，
C_beta(a)=max(P,N)。                                (11)
```

这里 N 只表示本节的负部分之和，不是旧证书中的 16^(2n)。
式 (11) 与原权重 v_k=D_k beta_k 完全相同；并非另选符号成本。
原逐项正性给非零 a 的严格界 |r(a)|<C_beta(a)。

设 mu_n=nu_n/beta_n，为概率测度。则

```text
U_n(a)=beta_n sqrt(E_(mu_n)[F_a²])，
P−N=beta_n E_(mu_n)[F_a]，
|P−N|≤U_n(a)。                                     (12)
```

RMS 支配均值绝对值，但它不直接支配或被 max(P,N) 支配；后者按系数符号分组。

### 5.1 一个对真实核也适用的统一上限

定义

```text
H_(i,j)=beta_n beta_(n+i+j)/(beta_(n+i) beta_(n+j))，
kappa_n²=beta_n beta_(3n)/beta_(2n)²。               (13)
```

有

```text
1≤H_(i,j)≤kappa_n²<16/9<2。                         (14)
```

证明：从 B_(m+1)/B_m=2(2m+1)/(m+1)，直接计算

```text
beta_(m+1)/beta_m=m²/[4(2m+1)²]。
```

这个比值随 m 严格增加。因此 H_(0,j)=1，H_(i,j) 随两个索引分别不减，最大值在
i=j=n，得到前两条不等式。另一方面，中央二项式系数的连续比值
B_(m+1)/B_m=4−2/(m+1) 严格增加，所以 B_(2n)²<B_n B_(3n)。代入式 (13)，

```text
kappa_n²=(16/9)*B_(2n)^4/[B_n² B_(3n)²]<16/9。
```

由 U_n(a)²=sum z_i z_j H_(i,j)，对同号项使用上界，对异号项使用下界，得

```text
U_n(a)²≤kappa_n²(P²+N²)−2PN
        ≤kappa_n² max(P,N)²。                       (15)
```

最后一步也可逐变量使用凸性：在 0≤P,N≤C 的正方形内，该二次式的最大值出现在顶点；
四个顶点值为 0、kappa_n² C²、kappa_n² C²、(2kappa_n²−2)C²。
因 kappa_n²<2，最大值是 kappa_n² C²。

因此对所有非零 a，包括真实整数核中的向量，有

```text
U_n(a)≤kappa_n C_beta(a)<(4/3) C_beta(a)。            (16)
```

这证明新上界不会比原符号成本大超过该常数因子，却没有证明 U_n(a)≤C_beta(a)。

对真实整数 E 核中的非零向量，第一条也可以加强为严格不等式

```text
U_n(a)²<kappa_n² C_beta(a)²。                        (16a)
```

因为实际 E_(2,k)>0 对全部 k=n,…,2n 成立，E a=0 排除了非零 a 的系数全同号。
于是 P>0、N>0。设 C=P≥N>0，则式 (15) 右侧与 kappa_n² C² 的差为
N(kappa_n² N−2C)<0；另一个大小次序对称。故式 (16a) 成立。

### 5.2 为什么不能直接称新二次型总更强

以下是系数空间中的两个精确多项式比较，不是满足 E a=0 的新 Sondow 证书。
其中有理系数可以统一清分母并吸收 D_k，变成整数 a；这不会自动使 E a=0。

取 F(t)=t，则

```text
C_beta=beta_(n+1)，U_n²=beta_n beta_(n+2)>C_beta²。   (17)
```

严格性来自上面 beta 连续比值的严格增加。此时新二次型上界较大。

反过来取 F(t)=1−[beta_n/beta_(n+1)]t，则 P=N=beta_n，且

```text
U_n²/C_beta²=H_(1,1)−1，
H_(1,1)=[1+1/(n(2n+3))]²，
0<H_(1,1)−1≤11/25<1。                              (18)
```

此时交叉项抵消给出严格更小的上界。因此两个泛函在整个系数空间没有单向顺序。
本文没有由这两个例子声称真实 E 核中也已经验证了两种比较方向；在真实核上目前
普遍证明的是式 (16)，没有另证 U_n≤C_beta。

### 5.3 可安全组合两个严格上界

对每条非零整数核向量，定义有理平方上界

```text
W_n(a)=min(U_n(a)²,C_beta(a)²)。                     (19)
```

两条原界都严格，因此 |r(a)|²<W_n(a)。对有效双向量把式 (9) 中的 M 替换为
max(W_n(a),W_n(b))，定理 2 原样成立。这个逐向量取较小值的组合证书至少与两种
单独证书分别同强，且允许一条向量使用矩界、另一条使用符号界。

其余未证义务没有改变：需要真实整数 E 核中的有效双向量，或无界参数上的相应构造；
正定性、有限层候选搜索和交叉项抵消本身都没有完成这一任务。

## 6. 从已认证商格下界转移有限障碍

本节只给一般判据，不包含候选生成器尚未独立核验的有限结果。
设 Lambda=ker_Z E、K=ker_Z(E,Q,T)，且 Lambda/K 的秩为 2。
在 M_n 所给的正定内积中，把 Lambda 正交投影到 span_R(K) 的正交补，得到有效商格。
对任意 a in Lambda，其投影的平方范数不超过 U_n(a)²。
完整核、完整商基与精确 Gram 矩阵的认证义务，与
[有效商格障碍说明](paper_sondow_quotient_obstruction_20260905_zh.md) 相同；
这里使用一般正定 M_n 替代原先的对角加权内积。

若这个商格的最短非零平方范数为 alpha，则每个有效方向 a in Lambda\K 满足

```text
U_n(a)²≥alpha。
```

因此有两个不同的转移判据：

```text
alpha>1        ⇒ 每个有效方向 U_n(a)²>1；
alpha≥kappa_n² ⇒ 每个有效方向 C_beta(a)>1。          (20)
```

第二条使用真实核中的严格式 (16a)。较粗而方便的充分条件是 alpha≥16/9，
它也可直接从严格界 U_n(a)²<(16/9)C_beta(a)² 得到。
两个有限排除结论只限制相应证书在该层的能力，不证明所有分母下界方法都无效。

### 6.1 二维 Gauss 基的第二连续极小值

设已认证的一组完整商格整数基具有 Gauss 约化 Gram 矩阵

```text
[[alpha,beta],[beta,delta]]，
0<alpha≤delta，2|beta|≤alpha。                      (21)
```

其第一、第二连续极小值的平方分别恰为 alpha、delta。第二个量的含义是：
所有整数线性无关向量对中，二者平方范数最大值的最小可能值。

证明：整数坐标 (x,y) 的平方范数为

```text
Q(x,y)=alpha x²+2 beta xy+delta y²。
```

当 y=0、x≠0 时，Q≥alpha。若 |y|=1，则
Q≥delta+alpha(x²−|x|)≥delta。若 |y|≥2，则配方给

```text
Q≥(delta−beta²/alpha)y²
  ≥(delta−alpha/4)y²
  ≥(3delta/4)y²≥3delta>delta。
```

因此任何不与第一基向量平行的整数向量都有平方范数至少 delta。
任何独立向量对中必有一条这样的向量；而两个基向量本身达到最大平方范数 delta。
同时第一基向量达到 alpha。证毕。

有效双向量 a、b 的投影彼此独立，故

```text
max(U_n(a)²,U_n(b)²)≥delta。                        (22)
```

所以 delta>1 已足以排除本层二次型的非平凡双向量证书，即使 alpha≤1。
delta=1 不足以排除，因为式 (10) 在 M=1 时仍给 q≥2。
同理，由式 (16a)，delta≥kappa_n² 足以推出每对有效双向量的
max(C_beta(a),C_beta(b))>1。这个第二连续极小值判据只排除合用的双向量，
不能反推出每个单独有效方向都满足 C_beta>1。

上述障碍仍须由完整格、整数可逆换基和精确有理等式认证。
一次 LLL/Gauss 候选输出或一次未找到低成本向量的搜索，都不是这些全称结论的证明。
